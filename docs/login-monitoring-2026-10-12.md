# 첫 로그인과 새 과제 모니터링 수정

이전 버전은 첫 로그인에서 조회 권한만 받았다. 학급 생성 때 파일 편집, 슬라이드 배부 때 전체 Drive 권한을 추가로 요청하고 계정 선택도 강제했다. 새 과제를 열면 기록 저장소는 읽었지만 저장 연결과 자동 확인은 수동으로 켜야 했다.

교사 로그인은 현재 기능에 필요한 네 권한을 한 번에 요청한다. 정상 응답을 조회·쓰기 세션에 함께 연결하고 학급·과제 생성, 메모·기록 저장에서는 유효한 같은 토큰을 사용한다. 일부 권한만 허용했거나 토큰이 만료되면 전체 연결이 완료된 것으로 취급하지 않는다. 계정 변경·로그아웃·설정 변경 시 이전 연결을 재사용하지 않으며, 로그아웃 뒤 도착한 OAuth 응답도 거부한다.

과제 화면은 사용자에게 추가 OAuth 동의를 띄우지 않고 첫 로그인의 연결로 저장소를 초기화한다. 학생별 중지·과제 종료 상태를 복원한 뒤 종료하지 않은 과제의 자동 확인을 시작한다. 최초 확인은 작업 증가량이 아닌 기준 상태이며, 다음 확인부터 실제 변화량을 기록한다. 약 30초 간격으로 보이는 화면에서만 확인하고, 숨겼다가 돌아온 기간은 연속 작업으로 계산하지 않는다.

시작과 동시에 중지 버튼을 눌러도 저장소 초기화를 공유하므로 과제 기록 저장소를 중복 생성하지 않는다. 준비 중 모니터링을 종료하면 첫 학생 조회도 시작하지 않는다. 저장된 종료 상태는 재접속해도 유지한다. 자동 연결이 실패하면 기존 기록을 표시하고 사용자에게 다시 연결을 안내한다.

토큰은 계속 브라우저 메모리에만 둔다. 이 변경은 기능마다 반복되는 로그인 제거이며, 페이지를 새로고침하거나 로그아웃하거나 토큰이 만료된 뒤에도 영구히 인증 없이 접속한다는 뜻은 아니다. 기존 Google 원본·학생 자료·기록을 삭제하거나 덮어쓰지 않는다. Google 콘솔 권한 설정이나 인증 제출은 변경하지 않았다.

검증은 모의 Google OAuth/API 및 실제 React 훅의 초기화·주기·중지·재접속 상태를 대상으로 한다. 실제 학생 파일에 시험 데이터를 쓰지 않았다. 최종 Google 로그인·동의 화면과 시연용 새 과제의 동작은 계정 사용자가 최신 배포에서 확인해야 한다.
