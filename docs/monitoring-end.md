# 수업 종료 후 기록 보기

과제 관찰 화면 상단에 ‘모니터링 종료’를 둔다. 첫 로그인에서 받은 조회·생성·저장 권한으로 과제의 저장소를 자동 연결한다. 종료하지 않은 과제는 연결 후 자동 확인을 시작하며, 저장된 종료 상태가 있으면 새 학생 자료를 조회하지 않는다. 연결이 만료되면 사용자가 ‘Google 다시 연결’로 갱신할 수 있다.

종료 즉시 이 화면의 자동 확인 타이머와 새 슬라이드·본문·댓글 조회를 멈춘다. 교사 비공개 과제 시트의 `settings` 이벤트에 `monitoringEnded: true`를 저장하고, 다시 접속하면 해당 상태를 복원한다. 학생별 중지 상태는 별도로 보존한다. 기존 기록·그래프·종합 기록·내보내기와 교사 메모는 계속 사용할 수 있다.

종료 저장에 실패하면 이 화면에서는 조회를 중지한 상태를 유지하고 ‘종료 상태 다시 저장’을 표시한다. 다음 접속까지 종료 상태가 유지된다고 주장하지 않는다. 재개는 저장 성공 후 허용하며 자동 확인은 시작하지 않는다. 종료 전후를 연속 확인으로 계산하지 않는다.

종료 후 도착한 본문·댓글 응답은 반영하지 않는다. 대기 중 스냅샷은 전송 직전에 로컬 상태와 이미 저장된 종료 상태를 검사한다. 다른 세션의 스냅샷 저장도 저장소의 종료 상태를 검사한다. 이미 Google로 전송된 요청은 사후 취소할 수 없으며 여러 브라우저 간 실시간 상태 전달은 제공하지 않는다. 이미 열린 다른 화면은 종료 상태를 다시 읽어야 새 조회도 중지된다. Google 원본 편집·학생 접속 링크·공유 권한을 종료하거나 삭제하는 기능은 아니다.

## 개인정보 등록 설명

현재 코드에서는 학생 자료를 운영자 서버의 별도 데이터베이스로 전송하거나 보관하지 않는다. 교사가 등록한 번호·이름/가명과 작업 자료는 교사의 Google 파일에 남으며, 브라우저가 Google API로 조회·연결·표시하고 작업 확인 기록·메모 등을 교사 시트에 저장한다. 호스팅 접속 정보와 교사 Google 로그인 정보의 처리는 학생 작업 본문 보관과 구분한다.

‘운영자 서버 별도 보관 없음’을 근거로 ‘학생 개인정보 처리 전혀 없음’ 또는 ‘에듀집 개인정보 항목 전부 해당 없음’이라고 답하지 않는다. 개인정보 보호법 제2조의 처리는 생성·연계·검색·이용 등도 포함한다. 공급자 역할, 학교 사용 근거, 위탁이나 제공 해당 여부는 실제 접근 권한·데이터 흐름·사용 조건에 따라 확인해야 하며 저장 위치 하나로 단정하지 않는다. 앱 이용 때문에 모든 학생의 동의서나 신상 정보를 운영자에게 별도로 수집해야 한다는 뜻도 아니다.

근거: [개인정보 보호법 제2조, 시행 2026.9.11](https://www.law.go.kr/LSW/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1026147155). 에듀집의 현재 점검 양식에서 이 구조에 해당하는 답변 및 적용 제외 항목은 등록 담당자에게 확인한다. 이 문서는 법적 역할에 관한 확정 판정이나 에듀집 심사 완료를 의미하지 않는다.
