## 중지 기능의 범위

중지 상태를 불러오기 전에도 새 학생 자료 조회를 시작하지 않는다. 중지 학생은 자동 수집, 수동 현재 작업 확인, 상세 본문 조회, 댓글 자동·수동 조회에서 제외한다. 댓글 쓰기도 앱에서 제한한다. 원본 슬라이드 외부 링크나 학생 자신의 Google 파일 편집 권한을 철회하지는 않는다.

늦은 본문·댓글 응답은 반영하지 않으며, 중지 후 빠르게 재개해도 이전 요청의 결과를 새 기록으로 취급하지 않는다. 저장 큐 대기와 비공개 저장소 조회 뒤 POST 직전에 다시 검사한다. 저장소에 이미 중지 이벤트가 있으면 다른 열린 앱에서 요청한 스냅샷도 추가하지 않는다. 예전 과제 카드의 학생 슬라이드 표지 조회도 중지 상태를 확인한다. 고정된 교사용 예시 표지는 학생 작업과 별개다.

이미 Google에 전송된 요청을 사후 취소할 수는 없다. 여러 컴퓨터의 열려 있는 페이지에서 진행 중인 요청을 원격으로 즉시 취소하는 기능도 아니다. 중지 저장 실패 시 현재 화면은 중지를 유지하고 ‘중지 상태 다시 저장’을 제공한다. 실패한 상태로 새로고침하면 이전 저장 상태로 돌아갈 수 있으므로 안내한다. 재개는 저장 성공 후 적용하며, 중지 전후를 연속 작업으로 판정하지 않는다.

## 실제 운영에서 남은 사항

1. 수업별 처리 목적·항목·공유 범위·보관 및 삭제 시점을 학생/법정대리인에게 안내한다. 동의가 필요한 경우 실제 동의와 확인 기록을 확보하고, 다른 적법한 근거를 사용하는 경우 그 근거를 확인한다. 앱의 교사 확인란만으로 법적 절차 완료라고 등록하지 않는다.
2. 학생/법정대리인의 열람·정정·삭제·중지 요청을 담당 교사가 처리하는 실제 담당·확인·결과 안내 절차를 정한다. 운영자 이메일도 실제로 확인하고 문의를 처리해야 한다.
3. Google 계정 종류와 적용 약관을 확인한다. 일반 소비자 Gmail/Drive는 Google이 별도 처리자 DPA를 제공하지 않는다고 설명하고, Workspace/Education/Cloud에는 CDPA가 적용될 수 있다. 계정 종류를 동일한 위탁관계로 작성하지 않는다.
4. Vercel 실제 플랜·적용 약관, 접속 정보 처리 및 Google 저장·공유에 필요한 제공/위탁/국외 처리 안내를 확정한다. 공개 DPA의 Pro/Enterprise 적용 범위를 Hobby에 그대로 가정하지 않는다. 이것만으로 유료 전환이나 등록 불가를 결론내리지 않는다.
5. 등록자료의 제품명을 G배움로그로 통일하고 미확정 체크리스트 항목을 재검토한다. 공급자 등록용 개인정보 동의는 학생 보호자 동의와 다르며 서명·동의 선택은 사용자가 수행한다.
