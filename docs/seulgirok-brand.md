# 슬기록 브랜드 가이드

## 브랜드 정의

- 이름: **슬기록**
- 의미: 슬라이드 기록 + 슬기롭게 기록
- 대표 문구: **슬라이드 수업의 과정을 슬기롭게 기록하다**
- 화면 문구: **슬라이드에 남은 작은 변화, 배움의 과정이 됩니다.**
- 대상: Google 슬라이드 수업에서 학생의 결과뿐 아니라 작업 과정을 살피는 교사

## 로고

노란 뒤쪽 슬라이드는 Google Slides 수업을, 초록 앞쪽 슬라이드와 기록선은 학생 작업의 변화가 쌓이는 과정을 뜻한다.

- 기본: `public/seulgirok-mark.svg`
- 단색: `public/seulgirok-mark-mono.svg`
- 어두운 배경: `public/seulgirok-mark-reversed.svg`
- 작은 크기: `public/seulgirok-favicon.svg`
- PNG: `public/brand/generated/`
- 파비콘: `public/favicon.ico`
- Apple 터치 아이콘: `public/apple-touch-icon.png`

로고 주변에는 아이콘 안쪽 점 지름의 두 배 이상 여백을 둔다. 기본 로고는 24px 미만에서 사용하지 않고, 16px와 32px에서는 작은 크기 전용 로고를 사용한다. 비율을 늘이거나, 지정 색 이외로 바꾸거나, 복잡한 사진 위에 외곽선 없이 올리지 않는다.

## 색상

| 역할 | 색상 |
| --- | --- |
| 깊은 초록 | `#203F35` |
| 기록 초록 | `#246B55` |
| 새싹 민트 | `#7FC5A2` |
| 슬라이드 노랑 | `#F9AB00` |
| 종이 배경 | `#F7F8F3` |

노랑은 슬라이드 상징과 중요한 기록점에만 제한해서 사용한다. 상태 경고나 일반 버튼에는 기존 상태 색을 유지한다.

## 글꼴과 말투

- 화면 글꼴: Pretendard, 시스템 한글 글꼴 순서
- 제목: 700~800, 자간을 좁게
- 본문: 400~600, 짧고 직접적인 문장
- 교사가 해야 할 행동과 확인할 결과를 먼저 말한다.

## 기존 자료 호환

- 새 Google 파일은 `슬기록_` 접두사로 만든다.
- 기존 `G배움로그_` 및 `SlideSight_DB_` 파일도 계속 검색하고 읽는다.
- 기존 파일 이름은 자동으로 변경하지 않는다.
- `gbaeumStore`, `gbaeumCreation` 등 내부 Google Drive 표식과 기존 브라우저 저장 키는 자료 연결을 위해 유지한다.

## 공개 전환 순서

현재 운영 주소 `baeumlog.chorok.app`은 새 도메인과 Google OAuth 설정이 준비될 때까지 유지한다. 코드와 화면 검증 후 도메인, OAuth 동의 화면, 개인정보처리방침 등록 정보, 에듀집 등록 정보를 같은 시점에 `슬기록`으로 전환한다.
