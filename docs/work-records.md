# 작업기록 화면과 데이터 기준

디자인 시안은 `/design-preview/dashboard`에서 확인한다. 실제 Google 데이터 연결은 `/next-version`에서 시작한다. 선택적 수집·피드백·비공개 메모 저장은 [live-workspace.md](./live-workspace.md)에 구현과 검증 범위를 정리했다.

## 화면

- 학생 카드는 등록 출석번호와 이름/가명을 표시한다. 빈 출석번호를 다시 매기지 않는다.
- 카드의 꺾은선과 본문/슬라이드 미리보기는 제거했다. 최근 확인 차이와 새 학생 답장을 표시한다.
- 상세는 전체 작업 요약/학급 평균 → 최근 변화 → 구간별 막대/작업기록 → 피드백 대화 → 교사 메모 순이다.
- 슬라이드 수는 현재 전체 장수다. 추가 글자와 이미지는 기본 템플릿을 제외한 현재 분량이다.
- 2시간 수업 예시는 연속 확인 기록을 20분 단위로 모은다. 장기 예시는 두 확인 시점 사이의 차이만 표시한다.
- 종합기록은 학생, 추가 글자, 슬라이드, 추가 이미지, 키워드, 피드백, 교사 메모만 표시한다.
- 시안 입력은 메모리에만 보관되며 새로고침하면 초기화된다. 댓글/답장 예시는 Google에 전송하지 않는다.

## 기록 근거

`first_snapshot`: 비교할 이전 확인 상태가 없다. 변화량은 null이다.

`continuous_poll`: 동일 수집 세션에서 연속 확인한 차이다. 확인 시각은 학생의 실제 수정 시각이 아니다.

`gap_comparison`: 서로 떨어진 두 확인 상태 사이의 차이다. 실제 작성 시각과 추가/삭제의 전체 횟수는 알 수 없다.

`legacy_unverified`: 기존 로그로, 추정 보간값이 섞여 있을 수 있다. 검증된 시계열/꾸준함의 근거로 쓰지 않는다. 기존 기록을 임의로 삭제하지 않는다.

급증 표시는 연속 수집의 60초 이하 구간에서 순증가 180자 이상일 때만 적용한다. 앱 복귀, 최초 확인, 숨겨진 탭 등 수집이 끊긴 경우에는 적용하지 않는다. 붙여넣기를 확정하지 않는다.

실제 코드에서 수정 이력 개수에 글자 증가량을 균등 배분하던 보간을 제거했다. 앱 진입 시 현재 상태를 확인한 시각에 첫 상태 또는 구간 비교로 저장한다. 과거 수정 이력은 최신 변경 참고만을 위해 읽는다.

## 실제 Google Sheets 저장 호환

기존 A:N 학생 필드는 유지한다. O열은 `last_checked_at`이다.

기존 A:G 활동 필드를 유지한다. H:M은 `record_source`, `previous_checked_at`, `student_number`, `char_delta`, `image_delta`, `slide_delta`이다. 읽기에는 열 확장이나 헤더 쓰기가 없다. 기존 앱에서 저장할 때만 확장을 수행하며, 새 필드 위치에 다른 헤더 또는 헤더 없는 데이터가 있으면 모든 쓰기를 중단한다.

교사 메모는 학생에게 공유되는 과제 시트에 저장하지 않는다. 새 버전의 과제별 교사 비공개 시트에 저장하며 쓰기 전에 소유자와 공유 권한을 검사한다.

## 내보내기

기존 `legacy_unverified` 기록은 한 좌표 안의 시간순 막대그래프로 표시한다. 첫 저장 상태는 비교 기준으로 두고 초기 템플릿·기존 분량을 작업 증가량으로 넣지 않는다. 이후 연속된 저장 수치의 순차이를 화면에서만 계산해 증가와 감소를 0선 위·아래에 표시한다. 날짜별 보기는 한국 날짜 기준으로 각 구간의 양수·음수 차이를 묶는다. 구간의 실제 작성량·작성 시각을 확정하거나 원본 `charDelta`를 변경하지 않는다.

`SYSTEM_BASELINE`의 등록 시각에 템플릿 포함 총량에서 템플릿 제외 수치로 바뀐 구간은 이전 글자·이미지가 템플릿 분량 이상이고 다음 수치가 템플릿보다 작은 전환에 한해 기준을 맞춰 비교한다. 기준 등록 전에 빈 파일에서 템플릿 글자와 이미지가 함께 추가되는 초기 전환은 작업량으로 추정하지 않고 비교 기준으로 재설정한다. 불명확한 전환은 미확인으로 남긴다. 원본 수치와 보정·제외 이유는 그래프 선택 상세에 보존한다.

기록이 없는 기간을 일별 작업으로 채우지 않으며 새 버전 전체 수치와 섞지 않는다. 긴 과제는 모든 기록을 보존하면서 인접 구간을 최대 48묶음으로 모아 한 그래프에 표시한다. 새 확인 변화도 같은 단일 좌표 그래프를 사용하며 검증된 확인 구간만 포함한다.

메인 학생 카드의 전체 글자는 새 버전에서 마지막으로 확인한 `currentCounts.charCount`이며 템플릿을 포함한다. 전체 수치가 없으면 기존 추가량에 템플릿을 더해 추정하지 않고 —로 표시한다. 상단 평균도 확인된 전체 글자 수만 집계한다. 최근 변화에는 검증된 두 확인 시각과 글자·이미지·슬라이드의 순차이를 함께 표시한다. 첫 확인, 과거 형식만 있는 기록, 비교 구간이 없는 기록은 증가량을 추정하지 않고 각각 안내한다. 종합 기록의 기존 추가량과 원본 행은 유지한다.

종합 CSV: UTF-8 BOM, RFC 스타일 따옴표/줄바꿈 처리, 수식으로 해석될 수 있는 입력은 텍스트 처리.

상세 JSON: schemaVersion, 예시 자료 표시, 과제/템플릿 기준, 학급 평균, 학생별 현재 현황, 확인 기록, 댓글/답장, 교사 메모, 답장 확인 시각, 급증 확인 상태와 필드 설명을 포함한다. unknown은 null로 유지한다. 인증 토큰이나 기존 집중도/참여 유형 판정을 내보내지 않는다.

## 연결 후 필요한 검증

실제 Google 댓글 생성/답장 조회, 직접 슬라이드에서 작성한 댓글 동기화, 작성자 식별, 확인 상태의 영구 저장, 교사 메모의 비공개 저장을 실계정으로 검증해야 한다. `author.me === false`만으로 학생이라고 단정하지 않는다. 확인되지 않은 작성자는 따로 분류한다.

기존 실제 대시보드의 UI는 구 버전을 유지한다. `/next-version`은 별도 인증으로 기존 파일을 새 화면에 연결한다. 저장된 상태를 실시간 슬라이드 상태로 표시하지 않는다. 학생 상세의 본문 확인에서 장별 텍스트·노트를 요청할 수 있고 원본 장으로 이동할 수 있다. 최신 편집 장은 추정하지 않는다. 댓글 조회와 새 기록 저장의 실제 권한은 별도로 연결한다.

구 버전의 키워드 전체 목록(`keywords_<spreadsheetId>`), 과제 종료 상태(`closed_<spreadsheetId>`)와 일부 템플릿 캐시는 기존 브라우저 localStorage에 있다. 새 화면은 과제별 비공개 Sheets `events`의 settings 키워드 목록을 우선한다. 등록 목록이 없으면 저장된 사용 키워드 합집합만 제공하며 전체 개수를 추정하지 않는다. ‘추가·수정’에서 저장한 전체 목록과 이후 수정·삭제는 다른 컴퓨터에서도 같은 계정으로 불러온다. 구 버전의 localStorage는 변경하거나 자동 이관하지 않는다.
